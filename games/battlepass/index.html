Battle Pass: MTX

A satire of live-service games. You run the studio, and the score is your player count.

You start with $5,000 and a story-heavy single-player RPG called Extraction Royale. Write code, fix bugs, set a price, run sales and reply to reviews. Then follow the money: relaunch it as Co-op, then Online, then Free-to-Play with a cash shop and a Battle Pass, and finally as a mobile port ("Don't you guys have phones?"). Each relaunch reaches more players and upsets the ones who liked the old game. Server outages, review bombs and investor calls land one at a time, and you fix each one by hand.
