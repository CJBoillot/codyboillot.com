Projects

Bakery storefront

The problem
A neighborhood bakery's order page took about six seconds to load on a phone, and customers gave up before ordering.
What I built
I measured the page, found three oversized images and a blocking script, resized the images and deferred the script. HTML, CSS and plain JavaScript.
The result
Load time on a mid-range phone dropped from about six seconds to under two.
What I'd do differently
I would set a size limit for images on day one so the problem couldn't come back.

Clinic sign-up form

The problem
A volunteer clinic's sign-up form couldn't be completed with a keyboard, which locked out some of the people it served.
What I built
I rebuilt the form with real labels, a visible focus ring and error messages a screen reader announces.
The result
The whole form can be filled in and sent without touching a mouse.
What I'd do differently
I would test with a screen reader user in week one, not week three.
