SkillTrainer: a training engine you can actually use

A skill-tree learning platform built from scratch, modeled on the pre-NGE Star Wars Galaxies skill window. Sections hold trees, trees hold columns of tiered modules, and each tier unlocks the next. Every module carries articles, media, downloads and a custom quiz, and the whole thing is authored in the browser. No backend, no framework, no build step.

The engine is the product: unlimited sections, trees and modules, a quiz builder covering multiple choice, multi-select, true/false and exact answers, and a full authoring UI that works on a phone. Content is plain JSON, so a tree exports as a file and installs by committing it.
